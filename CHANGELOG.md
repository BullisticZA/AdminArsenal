# Changelog

All notable changes to AdminArsenal are listed here.

## 2026-11-12

### Added
- **PassForge v1.0:** crypto-secure passwords and EFF-wordlist passphrases, strength meter, Pwned Passwords k-anonymity breach check.
- **PC Health v1.0:** scored Windows health report with HTML export, and preview-first cleanup.
- CI on Windows: lint, unit tests and smoke tests under Windows PowerShell 5.1 and PowerShell 7.
- Shield logo.

### Changed
- AIO Certs examples now use `example.com`.
